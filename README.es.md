# Portfolio Backend

[English](README.md)

Backend deprecado del portfolio personal original. Se conserva como implementación de referencia; el desarrollo del portfolio actual pertenece a los repositorios indicados abajo.

## Stack

Java · Spring Boot · Spring Security · JPA · MySQL.

## Alcance y configuración

Los controladores REST gestionan datos del portfolio y autenticación. Revisar la configuración de base de datos y aplicación antes del uso local. El descriptor Maven combina configuraciones Java y dependencias anteriores; no es una plantilla de despliegue.

## Desarrollo local

Usar un entorno compatible con el descriptor del proyecto.

```sh
mvn spring-boot:run
mvn test
```
